# במת הטנפורה 🎶

רקע חי למופעים ולאלתור בסגנון טנפורה הודית. הכלי משלב פלטת DJ, סינתיסייזר פדים ובונה ביטים בטאלות הודיות. הכל רץ בדפדפן, בקובץ HTML אחד, בלי התקנה ובלי שרת.

**נוצר על ידי:** בועז ברקת · [boaz-bareket.com](https://boaz-bareket.com)

**לפתיחת הכלי:** [boazbareket1.github.io/tanpura-stage](https://boazbareket1.github.io/tanpura-stage/)

---

## התחלה מהירה (דקה אחת)
1. בוחרים **סא**, הטוניקה, בשורת הצלילים שבראש העמוד. למשל C (דו).
2. לוחצים **▶ נגן** או **רווח**. הטנפורה והפד מתחילים לנגן.
3. מדליקים את **הביט** במקש `3`, או טוענים טרק מוכן מ"טרקים לדוגמה" (רגועים או מקפיצים).
4. בונים התפתחות: **▲ רמה** (או `N`) מעלה את כל הטרק צעד אחר צעד, ו־**▼ רמה** (או `H`) מרגיע.
5. מוסיפים צבע חי עם **פדי ההקשה**, במקשים `4` עד `0`.
6. להחלפת אווירה באותו סולם: בוחרים ביט בפאנל **"הטרק הבא"** ולוחצים `Enter`.
7. שומרים את הצליל שאהבתם: נותנים לו שם בראש העמוד ולוחצים **"שמור"**.

## העלאה לגיטהאב ופרסום באתר (GitHub Pages)

### שלב 1: יצירת מאגר חדש
1. נכנסים ל־[github.com](https://github.com) ומתחברים (משתמש `boazbareket1`).
2. לוחצים על **+** בפינה העליונה, ואז **New repository**.
3. ב־**Repository name** כותבים: `tanpura-stage`
4. בוחרים **Public**, כי GitHub Pages חינמי רק למאגר ציבורי.
5. לוחצים **Create repository**.

### שלב 2: העלאת הקבצים
1. בעמוד המאגר החדש לוחצים על הקישור **uploading an existing file**. במאגר שכבר יש בו קבצים זה נמצא תחת **Add file** ואז **Upload files**.
2. גוררים לחלון את שלושת הקבצים: `index.html`, `README.md`, `LICENSE`.
   חשוב: גוררים את הקבצים עצמם, לא את התיקייה שמכילה אותם.
3. למטה, ב־**Commit changes**, כותבים הודעה, למשל `גרסה ראשונה`, ולוחצים **Commit changes**.

### שלב 3: הפעלת האתר
1. במאגר לוחצים על **Settings**, ובתפריט הצד על **Pages**.
2. תחת **Build and deployment**, ב־**Source**, בוחרים **Deploy from a branch**.
3. ב־**Branch** בוחרים `main` ואת התיקייה `/ (root)`, ולוחצים **Save**.
4. מחכים דקה או שתיים ומרעננים. בראש העמוד יופיע הקישור לאתר:

   **https://boazbareket1.github.io/tanpura-stage/**

### עדכון גרסה בעתיד
נכנסים למאגר ולוחצים **Add file** ואז **Upload files**. גוררים את `index.html` החדש, והוא מחליף את הישן אוטומטית. לוחצים **Commit changes**, ותוך דקה האתר מתעדכן.

### דרך חלופית: שורת פקודה (git)
```bash
cd tanpura-stage
git init
git add .
git commit -m "גרסה ראשונה"
git branch -M main
git remote add origin https://github.com/boazbareket1/tanpura-stage.git
git push -u origin main
```
אחר כך מפעילים את Pages כמו בשלב 3.

## הערות חשובות למופע

- **הצליל מתחיל רק אחרי לחיצה על "נגן".** זו מגבלה של כל הדפדפנים.
- **טרקים שמורים נשמרים בדפדפן ובמחשב שבהם שמרתם אותם.** כדי להעביר טרק למחשב אחר, השתמשו ב"ייצא קובץ ‎.json" או ב"קוד שיתוף".
- **לפני מופע:** מומלץ לייצא גיבוי של כל הטרקים החשובים. ניקוי נתוני דפדפן מוחק את הספרייה המקומית.
- **במחשב המופע** כדאי לסגור לשוניות אחרות ולחבר מטען, כדי שהסאונד יהיה יציב.
- **האתר עובד גם בלי אינטרנט** אם שומרים את `index.html` במחשב ופותחים אותו בדפדפן. בלי חיבור יוצגו גופני מערכת במקום הגופנים המעוצבים, והסאונד לא מושפע.
- **דפדפנים מומלצים:** Chrome, Edge או Safari בגרסה עדכנית.
